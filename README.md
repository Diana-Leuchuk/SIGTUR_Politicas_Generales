SIGTUR - POLITICAS LEGALES COMPARTIDAS

CONTENIDO
- index.html: portada de documentos legales
- terminos-condiciones.html: condiciones de uso
- politica-privacidad.html: privacidad y protección de datos
- politica-cookies.html: política de cookies
- css/legal.css: estilos compartidos

COMO USAR
1. Subí todos los archivos y la carpeta css a un mismo directorio de tu hosting.
2. Abrí index.html para revisar la portada.
3. En cada uno de los documentos, completá los campos entre corchetes con los datos reales del responsable.
4. Revisá el código y las cookies reales de cada sitio antes de publicar. No inventes cookies, proveedores ni prácticas.
5. Los cinco grupos pueden enlazar a los mismos archivos si se publican en una ubicación común y los responsables y tratamientos son realmente los mismos. Si cada grupo administra su sitio de forma independiente, revisen si deben identificar responsables diferentes.
